# How Claude differs across languages

Claude's average lean on four value axes when conversing in each language, measured in standard deviations (σ) from the mean across all conversations. Each axis is a spectrum between two traits; a positive σ shows how far Claude leans toward the named trait. "average" means the language sits at the global mean on that axis.

The four value axes (left trait ↔ right trait):

- **Deference ↔ Caution**
- **Warmth ↔ Rigor**
- **Depth ↔ Brevity**
- **Candor ↔ Execution**

_Source: Anthropic research, "How Claude differs across languages" (Figure 4). 20 languages._
